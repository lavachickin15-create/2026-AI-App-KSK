# ♻️ AI 재활용 도우미 (Recycling Helper)

**책임감 있는 소비와 생산(SDG 12)**을 위한 AI 기반 올바른 분리배출 안내 서비스입니다. 
스마트폰이나 웹캠으로 쓰레기를 촬영하면, Google Gemini API를 활용하여 품목을 식별하고 올바른 분리배출 방법을 제안합니다.

## 주요 기능
- **AI 카메라 분석**: 쓰레기 사진을 찍으면 AI가 자동으로 품목 분류, 구체적 이름, 조치 방법을 판별합니다.
- **배출 이력 관리**: 스캔한 쓰레기 데이터를 누적하여 관리합니다.
- **통계 시각화**: 내가 배출한 쓰레기 종류를 원그래프로 보여주며, 플라스틱 배출 비중이 80% 이상일 경우 경고 메시지를 제공합니다.
